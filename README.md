# kadai2_APISearch

岡本の技術課題②公開API記事検索アプリ作成です。

## 調べたこと・詰まった点

### HTML

- aria-label<br>
  アクセシビリティのために、要素に名前を付けておくことができる属性のこと。<br>コードのレビュワーに対し、その要素が何を書いているのかを明示する役割もある。

- label for<br>
  aria-label同様に、アクセシビリティ(と可読性)のための要素。<br>特に、idを軸にしてどの要素が関連づいているのかを示す。<br>役割は命名のみであるため、labelそのものをjsやCSSで呼び出せるわけではない点には注意が必要である。

- Promise<br>
  非同期処理（すぐにはレスポンスの返ってこない処理）が~~成功したか、失敗したかの結果を返す~~オブジェクト。
  **→成功したか、失敗したか、処理中かの値を返す**

- fetch()<br>
  Promiseを返してくれるメソッド。

- **try-catchと.then.catch**<br>
  ~~この二つはともに、Promiseの結果にあわせて処理を書き込むためのものである。tryおよびthenは、成功した場合の処理を、catchは呼び出しに失敗した際の処理を書き込み利用する。<br>tryとthenの大きな違いは、**thenは次のPromiseをすぐに呼び出す**という点である。<br>今回は、APIを呼び出した後すぐさまjsonも呼び出すのでthenでも問題はない？→仕様書や相談など、感覚をつかむまでは適宜確認する。~~
  **→役割がそもそも違う。**
  - try-catch<br>
    tryの中に、失敗する可能性のある処理（Promiseなど）を書いておき、失敗した際の処理をcatchに書いておくもの。
    **→try-catchはPromiseなどに限らず、広い使用用途を持つ（配列への処理など）**
  - .then()
    Promiseの返り値がfullfilledだった際に、次に行う処理を書いておくもの。どちらかといえば機能はasync-awaitに近い。
    【疑問】<br>
    Q,なぜ.then()を使う際は今まで必要だったtryが不要になるのか<br>
    A,.then()は、前のPromiseの成功が前提にあるため。<br>
    そもそもawaitは前のPromiseの応答を待つものである。<br>
    **awaitをつけないと処理が勝手に行われる状態にあるからawaitが必要であり、本来成功失敗を問わず処理してしまうから、例外を監視したい処理範囲であるtryの中に入れている。**<br>
    先述の通り、.then()はもともと前のPromiseが成功する前提にある。Promiseが失敗すれば、catchに勝手に流れるようになっている。<br>
    awaitにはtry/catchを、.then()にはcatchをつける処理をそれぞれセットにしておく。

- async-await<br>
  awaitを利用することで、非同期処理中に、処理が完了していないまま次の処理に進むことを防ぐ（＝awaitを書いた位置で処理が完了するまで、一時停止する）ことができる。<br>asyncは、awaitを利用するため関数の前に必ず付与する。

- res.ok<br>
  APIからのレスポンスが成功したかを確認するために利用する。<br>
  戻り値はtrueかfalseであり、if文と併用することで、レスポンス成功時の処理と失敗時の処理を切り分けることができる。

- throw Error<br>
  res.okがfalseだった時の処理に今回は利用している。強制的にエラーを出し、try-catchのcatchに飛ばすことができる。<br>
  中に表記する文字に厳しいルールはないが、基本的にユーザーに表示したいもの・エラーの際に分析できるものといった、見てすぐに意味が理解できるものを記述すべきである。<br>

- URLの組み立て<br>
  PR2の第一回PR時点では、ユーザーの入力した内容がそのままクエリに直打ちされていた。これは、**ユーザーの利用時のバグの誘発や、悪意ある入力を受け付けかねない。**<br>
  対策には、URL()というコンストラクターがある。用途の幅が非常に広いので、今回は実際に記述したものにコメントを付与する。<br>

  // クエリを加えない素のURLを変数に格納
  const url = new URL("https://qiita.com/api/v2/items");<br>
  // .searchでURL内の？以降を指定。<br>
  // 入力された文字を、検索用に16進数と記号で表示するURLSearchParamsで変換<br>
  url.search = new URLSearchParams({<br>
  query: keyword,<br>
  page: "1",<br>
  per_page: "20",<br>
  });<br>
  // 確認用　console.log("URL組み立て成功");<br>
  // fetchするのは、先ほど設定した変数urlでよい。
  const response = await fetch(url);<br>
